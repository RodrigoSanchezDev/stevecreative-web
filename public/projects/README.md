# Project Screenshots

Place your project screenshots here. They will be served from `/projects/` on the website.

## Naming Convention

Use descriptive, kebab-case names:

```
project-1.png
project-2.png
project-3.png
project-4.png
```

## Recommended Specs

- **Format:** PNG or WebP
- **Aspect ratio:** 16:10 (e.g., 1920×1200)
- **Max size:** ~500KB per image (optimize with TinyPNG or Squoosh)
